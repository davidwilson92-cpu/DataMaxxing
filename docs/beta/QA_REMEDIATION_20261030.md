## AI decision

Production was confirmed to use gpt-5-mini. Four synthetic tasks were compared against gpt-6.1-terra twice. The first run had a local text-encoding issue and is provisional; the clean UTF-8 repeat is the reported comparison. No customer content or provider credentials were sent as test prompts.

| Task | GPT-5 mini | GPT-6.1 Terra |
|---|---|---|
| One-off Brixton class | Preserved time/one-off, 8.07s | Preserved time/one-off, 2.34s |
| Affiliate caption | Failed disclosure placement: copied “Start Ad …” into body, 8.19s | Correct opening disclosure and commission, 4.66s |
| Both-caption rewrite, scoped to one platform | Correct count, generic extra CTA, 5.78s | Correct count, concise supplied facts, 1.68s |
| Supplied A/B performance | Correct arithmetic, verbose; invented “limited stock” in proposed CTA, 19.49s | Correct rates, clear source caveat, one-variable experiment, 9.49s |

Recommend GPT-6.1 Terra for generation, rewrite, Next Move/strategy, voice inference and performance interpretation. OPENAI_CONTENT_MODEL now supports that separation from intent routing with per-request isolation. It is opt-in and has not changed production. GPT-5 mini is now marked deprecated in the official model catalogue, so retaining it for routing is only a short-term compatibility option, not a long-term launch recommendation; evaluate a supported inexpensive replacement separately before changing routing. Updated analysis prompts prohibit invented scarcity and target 120 words. This small evaluation is not a general quality benchmark or a guarantee of factual captions.

After the final prompt changes, Terra passed a further four synthetic editorial checks: one-off class 5.46s, affiliate disclosure 2.14s, paired rewrite 1.89s, supplied performance analysis 7.26s. A real Next Move generation against the candidate's strict three-action schema initially suggested a two-slide Story that Zova cannot automatically deliver. The capability instructions were tightened and the repeat returned three valid, distinct proposals in 9.24s: one coach video, one single-image Story and one equipment explanation. Each used the supplied strategy, voice, available evidence and time constraints. These bounded checks used synthetic content; no customer drafts or social credentials were included in model prompts. No production model setting was changed.

Official model pages: https://developers.openai.com/api/docs/models/gpt-6.1-terra and https://developers.openai.com/api/docs/models/gpt-5-mini. Terra standard text prices are $1 input/$5 output per million tokens. Mini is $0.25/$2. An illustrative 2,000-input/500-billable-output-token call is $0.0045 vs $0.0015, before retries, extra reasoning, images, tools and taxes. Actual task usage must be measured.
